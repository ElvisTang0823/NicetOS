# NicetOS
> A child-safe operating system based on Ubuntu LTS.
# 法律聲明：
1. ​免責聲明與權利邊界
​「本系統旨在協助過濾不當網路內容，但受限於技術與網路動態變化，無法保證 100% 的攔截效果。建議家長仍應保持對兒少網路行為的適當陪伴與監督。」
2. 著作權與授權遵循
​「本專案提供 Windows 執行檔。專案及其隨附元件可能採用不同的開源授權；各元件均應依其原授權條款使用與散布，相關授權與聲明以各元件所附文件為準。」
3. 個人資料保護
​「我們將隱私視為核心價值，系統採取『本地端優先』原則進行 AI 分析。所有過濾判斷所需的資料均在您設備本地處理，絕不主動將瀏覽紀錄傳送至外部伺服器。」
4. 兒少保護相關法規
​「本系統遵循相關兒少保護法規，並導入透明的攔截機制。若發生誤攔情事，使用者可透過專屬的異議系統提交反饋，我們將持續優化演算法以改善判斷精確度。」
