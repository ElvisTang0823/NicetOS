# NicetOS 更新與建置指南

## 目錄結構

- 根目錄保留原始檔：`main.go`、`main.py`、`data/`、`python/`
- `go/` 目錄放置 Go 套件實作與平台分支檔案，例如：`proxy_windows.go`、`transparent_linux.go`、`transparent_other.go`
- 專案現在使用的是同一個模組結構，編譯時不需要再複製 `main.go` 到 `go/`。

## 更新程式

1. 修改根目錄的 `main.go` 或 `go/` 內的 Go 原始碼。
2. 若修改 `main.py`、`python/` 或 `data/`，請直接維持在根目錄原位，不需要搬移。
3. 從專案根目錄執行 `go build` 或 `go test` 即可。

## 直接建置

### Windows（PowerShell）

```powershell
go build -o .\go\NicetOS-windows-amd64.exe .
```

執行：

```powershell
.\go\NicetOS-windows-amd64.exe
```

Windows 版本會自動設定系統 Proxy，按 `Ctrl+C` 後會恢復原本設定。

### Ubuntu（Linux）

```bash
go build -o ./go/NicetOS-linux-amd64 .
```

執行：

```bash
sudo ./go/NicetOS-linux-amd64
```

Ubuntu 版本需要 root 權限來建立透明代理的 `iptables` 規則；按 `Ctrl+C` 會自動移除規則。

### macOS

```bash
go build -o ./go/NicetOS-macos-amd64 .
GOOS=darwin GOARCH=arm64 go build -o ./go/NicetOS-macos-arm64 .
```

執行：

```bash
./go/NicetOS-macos-amd64
```

macOS 版本會使用標準 HTTP/HTTPS Proxy 模式，瀏覽器請設定為 `127.0.0.1:8080`。

## 交叉編譯範例

```bash
GOOS=windows GOARCH=amd64 go build -o ./go/NicetOS-windows-amd64.exe .
GOOS=linux GOARCH=amd64 go build -o ./go/NicetOS-linux-amd64 .
GOOS=darwin GOARCH=amd64 go build -o ./go/NicetOS-macos-amd64 .
GOOS=darwin GOARCH=arm64 go build -o ./go/NicetOS-macos-arm64 .
```

## 檢查與測試

```powershell
go test .
```

也可直接測試 Python 判斷：

```powershell
python -c "import sys; sys.path.insert(0, 'python'); import main; print(main.check_url('http://pornhub.com')); print(main.check_url('http://example.com'))"
```

輸出預期：

- `pornhub.com` → `False`
- `example.com` → `0`

## 清理建置產物

```powershell
Remove-Item .\go\NicetOS-* -ErrorAction SilentlyContinue
```

如需重新建置，只需重新執行上面的 `go build` 指令即可。

## 注意事項

- 不要再執行複製 `main.go` 到 `go/` 的舊流程。
- `Ctrl+C` 是正常停止方式，程式會在退出前清理系統 Proxy 或 `iptables` 規則。
- 若修改 Python 判斷邏輯，請確認 `main.py` 與 `python/hash.py` 的路徑正確，並在執行前使用 `PYTHONPATH` 或 `sys.path` 來載入。
