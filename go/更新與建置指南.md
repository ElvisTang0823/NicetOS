# NicetOS 更新與建置指南

## 目錄結構

- 根目錄保留原始檔：`main.go`、`main.py`、`data/`、`python/`
- `go/` 目錄放置 Go 套件實作與平台分支檔案，例如：`proxy_windows.go`、`transparent_linux.go`、`transparent_other.go`
- 專案現在使用的是同一個模組結構，編譯時不需要再複製 `main.go` 到 `go/`。

## 更新程式

1. 修改根目錄的 `main.go` 或 `go/` 內的 Go 原始碼。
2. 若修改 `main.py`、`python/` 或 `data/`，請直接維持在根目錄原位，不需要搬移。
3. 從專案根目錄執行 `go build` 或 `go test` 即可。

## 直接建置

### Windows（PowerShell）

```powershell
go build -o .\go\NicetOS-windows-amd64.exe .
```

執行：

```powershell
.\go\NicetOS-windows-amd64.exe
```

Windows 版本會自動設定系統 Proxy。詳細機制如下：
- **正常啟動**：自動檢查並清除任何遺留的舊代理設定（前次異常終止時的殘留）
- **正常退出**（Ctrl+C）：系統 Proxy 會自動恢復原本設定
- **強制終止**：下次啟動時會自動檢測並清除遺留設定，不會導致斷網
- **HTTPS 阻擋頁**：程式會在 `data/nicetos-proxy-ca-cert.pem` 建立本機 CA，啟動時只將它加入「目前使用者」的受信任根憑證，結束時移除。這讓 Chrome / Edge 可以顯示 NicetOS 的自訂阻擋頁，而不是 `ERR_TUNNEL_CONNECTION_FAILED`。

若要查看詳細的設定過程，可將標準錯誤重定向到檔案：

```powershell
.\go\NicetOS-windows-amd64.exe 2> proxy.log
```

### Ubuntu（Linux）

```bash
go build -o ./go/NicetOS-linux-amd64 .
```

執行：

```bash
sudo ./go/NicetOS-linux-amd64
```

Ubuntu 版本需要 root 權限來建立透明代理的 `iptables` 規則。詳細機制如下：
- **正常啟動**：建立 `iptables` 規則以攔截指定埠的流量
- **正常退出**（Ctrl+C）：自動刪除 `iptables` 規則
- **強制終止**：下次啟動時會刪除前次的規則再建立新規則
- **HTTPS 阻擋頁**：透明代理也使用 `data/nicetos-proxy-ca-cert.pem` 簽發網站憑證；首次部署後，管理員必須將此 CA 匯入裝置／瀏覽器的信任根憑證，瀏覽器才會顯示自訂阻擋頁。

若要查看詳細的 iptables 操作日誌：

```bash
sudo ./go/NicetOS-linux-amd64 2>&1 | tee proxy.log
```

### macOS

```bash
go build -o ./go/NicetOS-macos-amd64 .
GOOS=darwin GOARCH=arm64 go build -o ./go/NicetOS-macos-arm64 .
```

執行：

```bash
./go/NicetOS-macos-amd64
```

macOS 版本會使用標準 HTTP/HTTPS Proxy 模式，瀏覽器請設定為 `127.0.0.1:8080`。

## 交叉編譯範例

```bash
GOOS=windows GOARCH=amd64 go build -o ./go/NicetOS-windows-amd64.exe .
GOOS=linux GOARCH=amd64 go build -o ./go/NicetOS-linux-amd64 .
GOOS=darwin GOARCH=amd64 go build -o ./go/NicetOS-macos-amd64 .
GOOS=darwin GOARCH=arm64 go build -o ./go/NicetOS-macos-arm64 .
```

## 檢查與測試

```powershell
go test .
```

也可直接測試 Python 判斷：

```powershell
python -c "import sys; sys.path.insert(0, 'python'); import main; print(main.check_url('http://pornhub.com')); print(main.check_url('http://example.com'))"
```

輸出預期：

- `pornhub.com` → `False`
- `example.com` → `0`

## 清理建置產物

```powershell
Remove-Item .\go\NicetOS-* -ErrorAction SilentlyContinue
```

如需重新建置，只需重新執行上面的 `go build` 指令即可。

## 注意事項

### 編譯與執行
- 不要再執行複製 `main.go` 到 `go/` 的舊流程。
- 從根目錄執行 `go build` 即可編譯所有平台版本。

### 系統設定恢復機制
- **正常退出**（Ctrl+C）：程式會在退出前自動恢復系統設定
- **強制終止**（工作管理員/kill 指令）：下次啟動時會自動檢測並清除遺留設定，**不會導致斷網**
- **多個版本衝突**：若同時運行不同版本或埠，啟動時會檢測並清理舊設定

### 日誌記錄
所有操作都會輸出詳細日誌到標準錯誤，便於診斷：
- `[PROXY-WIN]`：Windows 系統代理設定相關
- `[PROXY]`：HTTP/HTTPS 代理請求相關
- `[CHECK]`：Python URL 檢查結果

### Python 判斷邏輯
- 若修改 `main.py` 或 `python/hash.py`，請確認路徑正確
- 程式會自動在根目錄查找 `main.py` 和 `python/` 目錄
- Python 子進程會自動設定 `PYTHONPATH` 環境變數

### 故障排除
若遇到問題，可嘗試：
1. **Windows 斷網**：執行 `reg.exe delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyEnable /f` 手動清除代理
2. **Ubuntu iptables 卡住**：執行 `sudo iptables -t nat -L` 查看規則，用 `sudo iptables -t nat -D` 刪除
3. **查看日誌**：啟動時將 stderr 重定向到檔案：`2> proxy.log`
